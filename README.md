# Anshuman Gupta — Portfolio

Premium multi-page portfolio for **Anshuman Gupta**, Digital Marketing & Growth Specialist.
Built as a static site — pure HTML/CSS/JS, no build step — ready for **GitHub Pages**.

## Pages
`index.html` · `about.html` · `experience.html` · `case-studies.html` · `performance.html` · `seo.html` · `websites.html` · `social.html` · `video.html` · `ai-systems.html` · `contact.html`

## Features
- Sticky glass nav, scroll progress bar, animated KPI counters, scroll reveals
- Recreated Google Ads / Meta / Search Console dashboards with real numbers + click-to-zoom proof screenshots
- Instagram reels & posts and YouTube videos play **inline** in a lightbox (no leaving the site)
- Filterable creative gallery, before/after slider, animated AI workflow diagrams
- Fully responsive; Sora + Inter type; accent `#2563EB` / `#10B981`

## Deploy to GitHub Pages
1. Create a repo (e.g. `anshuman-portfolio`) and push the **contents of this `portfolio` folder** to the root.
2. Repo → **Settings → Pages** → Source: `Deploy from a branch` → Branch: `main` / root → **Save**.
3. Your site goes live at `https://<username>.github.io/anshuman-portfolio/`.

`.nojekyll` is included so GitHub serves the folders as-is.

## Edit
- Text lives directly in each `.html` file.
- Media links (reels, posts, YouTube, Drive) live in `assets/js/data.js`.
- Colors, fonts and components live in `assets/css/style.css`.
